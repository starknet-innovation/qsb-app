# Dependencies

This archive contains project-authored TypeScript contracts and generated build metadata. Third-party implementations are not vendored. Bundles retain external imports resolved by the application's package-lock.json, including Zod (MIT), @scure/btc-signer (MIT), @scure/base (MIT), @noble/hashes (MIT), and AWS SDK for JavaScript v3 (Apache-2.0). Preserve each installed package's LICENSE/NOTICE when distributing a deployment image. See the repository's existing attribution and dependency notices for the Bitcoin/QSB solver artifacts; this archive does not replace those notices.
